TP1 - 1-tier Todo App with a window (Java 17+, Swing)

Compile:  javac *.java
Run:      java Main

Data is saved automatically in todo.dat (created next to the program).

Use: type a title and press Enter (or Add). Select a task and click
"Done / Undo" (or double-click it). Rules: a title is required and a
pending task with the same title cannot be added twice.
